Honest Questions

Why does Windows SmartScreen appear?

Because this is an independent desktop application without an expensive commercial code-signing certificate (which costs hundreds per year). Simply click More info → Run anyway. The entire app is safe and offline.

Can I backup my tasks?

Yes. With one click from the Command Palette, you can export your entire data as a standard .json file, or import an existing backup anytime.

Does it require an internet connection?

Never. The installer sets up the app completely locally. It will run normally even if your Wi-Fi is completely turned off.

What platforms are supported?

Currently built and tested for Windows 10 and Windows 11 (64-bit).
